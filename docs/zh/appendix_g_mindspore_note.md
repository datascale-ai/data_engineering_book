# 附录G：MindSpore 简介与致谢

## D.1 附录定位

本附录不承担完整框架手册的职责，只作为本书中若干数据工程实践页的一个补充说明：当读者需要在国产算力与配套软件栈环境下完成训练、微调、推理或教学复现时，MindSpore 可以作为一条可选实现路径。

## D.2 MindSpore 简介

MindSpore（昇思）是一个面向云、边、端场景的深度学习框架，强调易开发、高效执行和全场景适配。结合随书材料中提供的章节与项目页，它更适合被理解为一种工程实现入口，而不是脱离任务场景单独讨论的技术名词。

从本书关心的数据工程视角看，MindSpore 的价值主要体现在几个方面：一是支持从数据处理、模型训练到推理部署的相对完整链路；二是在动态图与静态图、自动微分、分布式并行等能力上提供较稳定的工程接口；三是对于需要围绕昇腾生态、课程实验环境或特定复现要求开展工作的团队，能够提供更贴近实际部署条件的实现基础。

因此，读者在阅读第十二篇中的专项数据集实践，尤其是涉及配套实现仓库、训练脚本组织和复现实验入口的页面时，可以把 MindSpore 视为本书实践链路中的一个可选框架支点，而不必把它理解为独立于数据工程之外的附加内容。
